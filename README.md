# Kopanong Kotas Restaurant Website 

**Student No:** ST10525115
**Website:** Family-owned kota restaurant in Brixton, Johannesburg - Est. 2004

## Project Description
This is a responsive 5-page website for Kopanong Kotas Restaurant at 87 High Street, Brixton. The business started in 2004 as fruits & veg, expanded to cooked meals in 2006, and added famous kotas in 2010.

## Changes from Part 1
- Migrated ALL inline CSS to external file CSS/style.css
- Added 3 breakpoints: mobile (320-768px), tablet (769-1024px), desktop (1025px+)
- Added flexbox & CSS Grid (grid collapses 3→2→1 columns)
- Added new classes: kasi-stripe, badge, btn-uber, btn-whatsapp, map-frame, gallery-img

## File Structure
- home.html, about.html, services.html, gallery.html, contact.html, references.html
- CSS/style.css
- Images/ (6 images + Logo)
