## What I Improved - Part 3

1. From the feedback I got from my lecturer I was supposed to link my external CSS file with my HTML web pages using this tag on all my web pages.

3. I am also required to add date time update on all my web pages using JavaScript.
   - I added real-time date time on home.html that updates every second using setInterval()

4. I am also required to add SEO features.
   - I added sitemap.xml with all 5 pages and robots.txt with User-agent Allow
   - I added <title> tags optimized for "Best kota Johannesburg Brixton" and meta keywords and description on all pages

5. For Part 3 I am required to add Interactive Map, Gallery Lightbox, and Search Feature.

   - Added Lightbox on gallery.html - click image to open full screen with prev/next (Gallery Lightbox rubric)
   - Added Search bar on services.html to filter kota menu by name (Dynamic Content and Search rubric)

6. I deployed all pages to Azure without errors.
   - Tested home, about, services, gallery, contact, sitemap.xml, robots.txt - all load
